# Интеграция BingX

- Единственный источник URL: REF_BINGX в assets/config.js. URL в Markdown/TXT — сгенерированные результаты, а не независимые настройки.
- Все рекламные кнопки содержат пометку и полный риск; target=_blank и rel=sponsored noopener noreferrer.
- data-placement: header, footer, coin, table, signal-oi, signal-funding, signal-cvd, report-top, report-bottom, exchange, mobile.
- Ссылка приглашения не открывает ордер конкретного инструмента и не подтверждает наличие пары на BingX.
- Никаких действий по чужим чатам, комментариям и автопубликаций.

## Счётчики

На where-to-trade.html показываются только клики текущего браузера. Хранилище cs-referral-clicks-v1, без cookies и идентификаторов пользователя.
После подключения проверенного Umami или Plausible отправляется referral_click с exchange и placement.
В проекте пока нет настроенного внешнего сборщика. Общая статистика, регистрации и доход не подтверждены.
Ошибки localStorage/аналитики не блокируют навигацию. Закрытие мобильной панели не считается переходом.

## Публикация

Все изменения проходят отдельные PR и независимое ревью Claude. Не сливать цепочку автоматически.
Сейчас отдельные страницы монет, реальные подтверждённые аномалии и архив ежедневных отчётов ещё не реализованы.
Для карточек монет ссылка работает в существующем интерфейсе. Для аномалий и отчётов подготовлены компоненты, без вымышленных событий.
Текст для описания репозитория/Pages находится в github-pages-description.txt. Настройки GitHub этим PR не изменяются.
Перед публикацией шаблонов проверить ограничения длины и оформление целевой площадки.
