# Реферальные баннеры в ежедневных отчётах

Существующих ежедневных отчётов в репозитории пока нет. Генератор не придумывает рыночные данные.
После подготовки проверенного текста с источниками и временем:

```sh
node scripts/render-daily-report.cjs input.json reports/YYYY-MM-DD.html
```

Вход: `date` в формате YYYY-MM-DD и непустой `text`. HTML из текста экранируется.
Выход имеет баннеры `report-top` и `report-bottom`, общие шапку/подвал и дисклеймеры.
Упаковщик допускает только reports/YYYY-MM-DD.html; JSON-входы не публикуются.
Сам файл отчёта должен пройти отдельное ревью перед включением в публикацию.
Перед публикацией сверить description с содержимым отчёта; автоматически посты не отправляются.
