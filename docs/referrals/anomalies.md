# Блоки подтверждённых аномалий

В текущем продукте нет генератора подтверждённых аномалий OI/funding/CVD.
Обычный снимок метрики не считается торговым сигналом.

В будущем рендерере после проверки условия использовать:

```js
const html = CSReferralMarket.signalBlock(kind, confirmed, CSReferral.block);
```

`kind`: `oi`, `funding` или `cvd`. Только строгое `confirmed === true` создаёт CTA.
Блок содержит пометку, дисклеймер и placement `signal-oi|signal-funding|signal-cvd`.
Он ведёт на общую страницу приглашения, не в ордер конкретного инструмента.
Нельзя показывать его как подтверждение прибыльности события.
