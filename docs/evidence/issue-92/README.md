# Issue #92 — проверка сцены

[1440 px](sphere-1440.png) · [430 px](sphere-430.png) · [390 px](sphere-390.png) · [320 px](sphere-320.png) · [Панель целиком](market-1440.png) · [Запись, 3 секунды](sphere.mp4)

Скриншоты и запись сняты в Chromium с отключённым WebGL. Данные графиков на полном скриншоте поступают из тестовых фикстур Playwright. Публичная сборка получает их из существующих адаптеров. Сцена рисуется на Canvas 2D с трёхмерной проекцией, отдельно от торговых потоков.

Chromium 156.0.8078.79 headless, Debian 13, AMD EPYC 9V74, viewport 1440×850, DPR 1. За окно около 2 секунд измерено 120 кадров, интервал от первого до последнего 1,983 с (около 60 кадров/с), p95 интервала 16,8 мс. CDP за то же окно измерил 0,763 с задач основного потока страницы, 0,087 с скриптов и изменение JS heap +190 312 байт. Метрики захватывают всю страницу, включая графики. Физический телефон и нагрузка GPU в этом прогоне не измерялись.

Для BTC, ETH и SOL используются локальные графические логотипы из Simple Icons 15.0.0. Рынки с неподтверждённым логотипом используют нейтральный знак. [Логотипы и лицензия Simple Icons](https://github.com/simple-icons/simple-icons/tree/15.0.0)

Расчёт свечей и CVD остаётся в независимых модулях рынка. Будущий OpenAI-адаптер может читать их нормализованные результаты как отдельный потребитель. Сцена получает только выбранный идентификатор актива.
