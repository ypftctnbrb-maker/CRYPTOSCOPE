name: cryptoscope-handoff
description: Transfer a CRYPTOSCOPE issue, draft PR, release check or unfinished investigation to the next maintainer with verified GitHub references and reproducible evidence.
---

Use the Issue or PR that the task authorizes. For a private handoff draft, write it to a temporary file. Link existing evidence instead of duplicating logs, screenshots or specifications.

Include the repository and task number, working branch, exact base and HEAD SHAs, and the scope decision. List commands actually run with exit codes and the environment used. Mark fixtures, live results and read-only observations distinctly. Describe each blocker or unverified acceptance criterion with the next authorized check it needs.

Use canonical GitHub URLs and distinguish a draft PR from a release. Redact secrets, credentials, session identifiers and private personal data. Add queue markers only as directed by the current task. Before sending, verify the intended destination and any references that can change.
