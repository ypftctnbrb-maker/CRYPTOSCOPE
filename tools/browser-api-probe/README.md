# Browser/API Probe 1.0 · локальный стенд

Сценарии запускаются только на синтетических инструментах. Стенд ничего не отправляет в production или к биржам. Сервер и API слушают **127.0.0.1** на разных портах для проверки CORS самим браузером. Сведения о регионе, ОС, браузере и сети вводятся вручную и хранятся только в открытой вкладке и её локальном экспорте; не вводите IP, имена и адреса. Сервер не записывает клиентские адреса.

## Запуск и проверки

Node.js 22+ и npm. Установка затрагивает только этот каталог.

```sh
cd tools/browser-api-probe
npm ci --ignore-scripts
npm start
# Открыть http://127.0.0.1:8780
```

Заполните поля, выберите один сценарий и тип инструмента. Для короткой проверки укажите 1 повтор. Для первичной разведки доступно до 30 повторов с паузой 1,5 с между испытаниями; можно делать меньшие серии в разные дни. Серии условно одинаковых локальных заглушек не доказывают 99% доступности. Остановка завершает текущую проверку, а оставшиеся строки экспортируются как «НЕ ЗАПУЩЕНО». JSON/CSV можно скачать во время прогона. Сохраните предыдущий экспорт перед началом новой серии.

```sh
npm test
CHROME_BIN=/usr/bin/chromium npm run test:browser
```

Без `CHROME_BIN` используется браузер Playwright, если он установлен. Браузерные тесты используют сокращённые таймеры и реальные loopback-соединения. Ручной режим использует REST timeout/WS open timeout 10 с и WS окно наблюдения 60 с. Для холодного резерва стенд синтетически отказывает в начальной и повторной WS-сессиях и затем делает локальный REST ticker. Операции записи/торговли отсутствуют.

## Как читать экспорт

- **ПРОЙДЕНО** — читаемый 2xx и валидный формат REST либо завершённое WS-наблюдение без ожидаемых нарушений протокола. Spot OI/funding имеют статус **НЕ ЗАПУЩЕНО**. Время, тикер, свечи, сделки и перпетуальные OI/funding содержат искусственные данные.
- **ОШИБКА** содержит наблюдаемый класс. Читаемый 451 даёт `httpStatus=451`. В заглушке «451 без CORS» сервер отдал 451, но клиент видит только отказ fetch и отмечает **НЕОДНОЗНАЧНО**. Обычный отказ fetch не позволяет различить отсутствие CORS, DNS, TLS и другие причины. Успешный `no-cors` даёт непрозрачный ответ и также считается **НЕОДНОЗНАЧНО**.
- `T_open`, `T_ack`, `T_first`, `T_trade` измеряются от начала каждой попытки в мс. `T_first` — первый доставленный frame, `T_trade` — первая валидная сделка. ACK может быть предусмотрен и пропущен, либо явно отсутствовать в протоколе (`not-in-protocol`).
- Частота делится на наблюдавшееся время после открытия. Максимальная пауза включает отрезки между открытием, кадрами и концом окна. Дубликаты и скачки ID считаются для синтетического источника с последовательными ID. При переносе на другую схему проверить гарантии последовательности.
- Heartbeat без сделок завершает окно успешно, `T_trade=null`. Полностью молчащий синтетический поток имеет класс `no-message`. Успешные 1000/1001 до конца окна — **НЕОДНОЗНАЧНО**, 1011 — наблюдаемая ошибка. При обрыве TCP 1006 сообщает клиент; сервер не отправляет такой close frame. Повтор и холодный резерв сохраняются в отдельных полях, исходный сбой остаётся видимым.
- UTC, метаданные, исходные строки, задержки, ошибки и результаты повторов присутствуют в JSON и CSV. CSV хранит вложенные поля как JSON и экранирует начальные символы формул.

## Справочник реальных endpoints для будущего этапа

Пути сверены **22.11.2026** с официальной документацией. Таблица описательная, код стенда её не использует. Реальных запросов к биржевым API не было. Для будущего браузерного CORS нужен отдельный согласованный HTTPS origin и повторная проверка текущих лимитов, доступности и схем.

| Рынок / данные | Путь или поток | Официальная документация |
|---|---|---|
| Spot REST время, цена, свечи, агрегированные сделки | `GET /api/v3/time`, `/api/v3/ticker/price`, `/api/v3/klines`, `/api/v3/aggTrades` | [Binance Spot REST](https://github.com/binance/binance-spot-api-docs/blob/master/rest-api.md) |
| Spot WS сделки | `<symbol>@aggTrade`. URL-подписка и командный `SUBSCRIBE` отличаются наличием подтверждения | [Binance Spot WebSocket streams](https://github.com/binance/binance-spot-api-docs/blob/master/web-socket-streams.md) |
| USDⓈ-M Futures REST OI, funding snapshot | `GET /fapi/v1/openInterest`, `GET /fapi/v1/premiumIndex` | [Binance Futures market data](https://developers.binance.com/en/docs/catalog/core-trading-derivatives-trading-usd-s-m-futures/api/rest-api/market-data) |
